# 运行环境接入合同

任何运行环境接入 VOCtools 时必须提供以下能力，适配层不得改写研究规则。

## 加载

1. 以 `INSTRUCTIONS.md` 为入口。
2. 按入口引用读取 `soul.md`、`TASK_CONTRACT.md` 和命中的 `workflows/`。
3. 仅在选定平台、内容模型或 Provider 后读取对应文件。

## 工具与文件

- 提供任务目录的读写能力，并保持 UTF-8、原始响应和相对路径稳定。
- 向能力匹配阶段暴露当前任务真实可调用的操作及其运行时 Schema。
- Provider 调用结果必须能够原样写入 `collection/raw/`。
- 不得把已安装、已配置或已授权等同于当前任务可调用。

## 用户确认

- 将方案、查询、Provider 绑定、成本和扩样范围的确认写入 `research.json.approvals`。
- 确认记录必须包含被确认对象的 SHA-256、确认时间、范围和状态。
- 采集范围确认使用 `TASK_CONTRACT.md` 规定的规范字段和顺序计算哈希，其中包括调研用途和目标用户，不能只对自由文本说明计算。
- 参数、成本上限、Provider、查询或扩样边界变化时创建新的确认记录。

## 暂停与恢复

- 调用前写请求事件，调用后写终态、raw 路径和可复算的响应 SHA-256。
- 状态为 `unknown` 的请求先核对服务端和 raw，不得静默重发。
- 恢复只执行已批准范围内明确未完成的请求。

## 错误返回

适配层将运行时错误映射为核心通用错误枚举，并保留原始错误摘要；不得自动换 Provider、改查询或放宽纳入规则。
