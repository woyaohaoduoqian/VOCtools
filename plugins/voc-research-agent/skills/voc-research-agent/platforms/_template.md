# 平台画像模板

新增平台画像时复制本模板,所有字段必填,写不出来的字段说明为什么写不出来。画像只写研究特性,**不写采集工具细节**(工具、价格、字段在 data-collection 能力清单里,单一事实源)。

```markdown
# 平台名

- **接入状态**:已接入 / 未接入(未接入的平台可以推荐,但必须告知用户暂无法采集;以 data-collection 的 registry.json 为准)
- **画像状态**:初稿(未经实际调研校准)/ 已经 n 次调研校准(画像内容是初稿时是推断,只有被侦察和实际调研验证过才算校准)
- **一句话定位**:这个平台的数据本质是什么
- **谁在上面、说什么**:主要人群、内容形态(长文/短评/视频)、语言氛围
- **适合回答的问题**:2-4 条典型研究问题类型
- **不适合 / 取样偏差**:这个平台的数据天然缺什么、偏向谁;用它下结论时必须带的限定
- **典型起点**:在这个平台上,调研通常从什么切入(关键词/社区/账号/商品链接)
```
